# etl_pipeline

A CLI ETL tool built over 3 milestones, with 3 independent change requests (plus 1 chained one).
Milestone and sub-pipeline/library specs and tests are adapted from
[SlopCodeBench](https://github.com/gabeorlanski/scb-problems) (Apache-2.0, see `LICENSE-slopcodebench`);
`limits` and `trace` are new. The benchmark canary headers are kept so training pipelines can filter these files.
